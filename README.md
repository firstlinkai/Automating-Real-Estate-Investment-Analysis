# Automating Real Estate Investment Analysis with n8n

This project delivers a simple and practical automation system for real estate investors, brokerages, and property analysts. Built in n8n, it handles property sourcing, scoring, and agent outreach without manual research or data entry.

## How It Works

1. Pull property data from platforms like Immometrica and ImmoScout24.  
2. Merge all listings and normalize key fields so the data stays consistent.  
3. Score each property from 0–100 based on ROI, price range, condition, size, and location.  
4. Save all listings and details to Google Sheets for tracking and reporting.  
5. Send personalized HTML emails through Gmail to agents for properties that score 60 or higher.  
6. Generate a daily 8 AM report covering total listings, new entries, top cities, and ROI averages.  
7. Update records with email status to keep the entire workflow transparent.

## Why This Matters

- Instant property evaluation without spreadsheets  
- Scaled, personalized agent outreach  
- Daily performance insights with no manual effort  
- Useful for investors, brokerages, and property analysts
